# Executive PMO — Teamo 0.12.0

این مرحله روی دید مدیریتی چندپروژه‌ای تمرکز دارد:

- Resource Planning و تشخیص Over Allocation
- Dependency Map بین پروژه‌ها و وضعیت Blocked
- Budget / Cost Tracking شامل Planned، Actual و Forecast
- RAG Health خودکار بر اساس وضعیت پروژه، Risk Score، هزینه و وابستگی‌ها
- Executive Health Score برای Portfolio
- داشبورد مدیریتی پروژه‌ها با Progress، Risk، Dependency و Cost

داده‌ها به صورت آفلاین در SQLite ذخیره می‌شوند و از پروژه‌ها و Risk Register موجود تیمو استفاده می‌کنند.
