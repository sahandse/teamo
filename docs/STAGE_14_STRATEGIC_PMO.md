# Teamo 0.14.0 — Strategic PMO

این مرحله لایه تصمیم‌گیری مدیریتی تیمو را کامل می‌کند:

- Scenario Planning و What-if Analysis
- سنجش اثر تغییر بودجه، زمان، ظرفیت و ریسک
- Earned Value Management با PV / EV / AC / BAC
- محاسبه CPI / SPI / CV / SV / EAC
- Portfolio Prioritization با Strategy / Value / Risk / Effort و Mandatory
- Benefits Tracking با Target / Current / Owner / Due Date
- Executive Portfolio Report قابل کپی و خروجی متنی
- دیتابیس نسخه 12 با جداول Strategic PMO

## قبل از انتشار

بعد از Merge این مرحله، یک دور Release Readiness انجام می‌شود: Analyze، Build APK، پاک‌سازی هشدارهای قابل رفع، بررسی نسخه و مستندات. ایجاد Tag/Release فقط بعد از تأیید کاربر انجام می‌شود.
