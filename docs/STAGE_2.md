# Stage 2 — Offline Kanban

در این مرحله هسته مدیریت کارها از حالت نمایشی خارج شد:

- SQLite آفلاین برای نگهداری تسک‌ها
- مدل Task با وضعیت و اولویت
- Repository و Store برای CRUD
- ساخت تسک از داخل برنامه
- حذف تسک
- Drag & Drop واقعی بین ستون‌های کانبان
- ذخیره وضعیت جدید کارت پس از جابه‌جایی
- اتصال آمار داشبورد به داده‌های واقعی تسک‌ها

مرحله بعد: ویرایش و جزئیات تسک، پروژه‌های واقعی، پیگیری‌ها و تقویم شمسی.
