# Strategic PMO formulas

- CPI = EV / AC
- SPI = EV / PV
- CV = EV - AC
- SV = EV - PV
- EAC = BAC / CPI

Portfolio priority score uses weighted Strategy and Value with Risk/Effort penalties and an optional Mandatory boost.
Scenario score is an internal What-if comparison indicator derived from capacity, risk, schedule and budget deltas; it is not a probabilistic forecast.
